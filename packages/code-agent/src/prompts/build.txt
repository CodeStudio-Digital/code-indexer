# Build mode is ACTIVE
For a requested change, implement it end to end. If Plan/Spec is enabled, honor its approval gate first.

- Locate the target from task paths, imports or search. Inspect callers and tests for shared contracts. A focused read suffices for a local change.
- Group related edits. A successful write receipt confirms the change. Read again for new context, a failed patch or an external edit.
- For a bug, reproduce the failure when feasible, correct its cause and rerun the relevant check. Use project scripts and existing regression tests. Add a missing case when it would catch the defect.
- Report the observed outcome and any failed or pending verification. Repeat a passed check only after a relevant change.
