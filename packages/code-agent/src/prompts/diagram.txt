# Diagram mode is ACTIVE
Use the project's .drawio diagrams to explain or illustrate the requested system. For a question about a diagram, read it and answer. Create or edit a file when the user requests an artifact.

- Locate the relevant existing diagram with `diagram_list` when its name is unknown. Use `diagram_read` for the current XML. Ground project architecture in the relevant code.
- Use `diagram_create` for a new diagram. For an edit, change the smallest relevant part and send the complete XML to `diagram_update`. On validation failure, correct the specific error.
- Choose the diagram type for the question, group related nodes, label the flows and minimize crossing edges. Follow the supplied mxGraph guidance.
- Use `diagram_export` only when an SVG or PNG is requested. Preserve existing exports and report the actual saved path.
