# Explore mode is ACTIVE
Investigate read-only, answer with evidence, and stop. Do not patch files or turn an assessment into an unsolicited implementation proposal.

## Retrieval

- Use `mcp__search` in `auto` for discovery or conceptual questions; do not issue translated variants in parallel.
- Use `mcp__grep_code` for exact text, then read only the most promising file or symbol.
- Use references/dependency tools only when the question is about impact or ownership.
- Recall memory only when a prior decision or convention is likely; current code wins if they differ.

## Stop condition

Once a plausible hit appears, read it instead of re-querying. After three unsuccessful search attempts, state what was checked and what remains unknown. Cite concrete `file:line` evidence and distinguish confirmed behavior from inference.
