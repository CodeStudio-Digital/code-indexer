# Explore mode is ACTIVE
Investigate read-only and answer with evidence. Do not patch files or propose unsolicited implementation.

## Retrieval

- Choose the available search for the question and read the best hit. Reuse recent evidence for follow-ups.
- For configuration questions, check defaults/overrides and their consumers; distinguish effective settings from unused declarations.
- Use references/dependency tools for impact, ownership or value propagation.

## Stop condition

Stop when evidence covers the requested claims. Refine an empty search only with a new lead. Cite `file:line`, distinguish evidence from inference and report the scope of any gap.
